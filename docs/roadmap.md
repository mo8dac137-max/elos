# ELOS — خارطة الطريق المشتركة (مرحلية بمعايير قبول)

**الإصدار:** v1.0 — 2026-11-08 · **معدّها:** المشرف الرئيسي · **اعتماد الاتجاه:** المالك
**مرجع الصلاحيات:** `docs/design-partner-brief.md` v1.2 (القسمان 5 و11)

> قاعدة الخارطة: كل مرحلة **صغيرة قابلة للدمج مستقلة**، بمعايير قبول قابلة للقياس،
> وتمرّ بدورة العمل الواحدة نفسها: تكليف → تسليم [DELIVER] → مراجعة [REVIEW] →
> اختبارات → قياس حي 360px → دمج → نشر → تحقق إنتاجي → تسجيل. لا مرحلة تُفتح
> قبل إغلاق سابقتها (يسمح فقط بتوازي «مواصفة المرحلة اللاحقة» مع «تنفيذ الحالية»).

## الموجود الآن (خط الأساس عند اعتماد هذه الخارطة)

72 كلمة (3 دفعات) + 11 وحدة قواعد = 83 وحدة · قارئ ذكي بـ6 نصوص و20 صيغة شاذة ·
قاموس صوتي أوفلاين · مزامنة Supabase + نسخ احتياطي · 226/226 اختبارًا ·
منشور على GitHub Pages (CI يبني وينشر) · 48px لمس + قناة حالات غير لونية + بوابتا
حماية (inline-styles ratchet + reader-styles guard).

## المرحلة WP (قريبة — جارية الآن)

| # | المهمة | المالك التنفيذي | معايير القبول |
|---|---|---|---|
| WP-3 | تعريب الواجهة | مواصفة: المشرف (منجز، بانتظار اعتماد المالك) · تنفيذ: المشرف · مراجعة أطوال/RTL: الشريك | (1) اعتماد المالك للجدول الـ132 سطرًا (2) كل الهيكل عربي RTL والمحتوى التعليمي إنجليزي (3) صفر تجاوز 360px بقياس حي (4) عزل اتجاه للسلاسل المختلطة (5) 226+ اختبارًا أخضر (6) لا تغيير في قيم بيانات الحالات |
| WP-4 | نظام الأيقونات SVG | الشريك (قراره النهائي) · دمج: المشرف | (1) SVG مضمّنة 24px شبكة وcurrentColor (2) قاموس أيقونات موثق بملف واحد ≤400 سطر (3) لا مكتبات خارجية (4) تباين كافٍ وتلميح بديل نصي (5) قياس حي 360px + اختبارات خضراء |

## المرحلة L — تعميق التعلّم (التطوير الكبير القادم، الشريك الأول)

| # | المهمة | المالك التنفيذي | معايير القبول |
|---|---|---|---|
| L1 | الدفعة الرابعة (pay/nurse/card/bill/way/get/think/listen/live + مرشحات) | صياغة المحتوى: الشريك · تدقيق ودمج: المشرف | (1) 96 كلمة A1/A2 بتقاطع NGSL×سيناريوهات المالك (2) 3 تمارين متدرجة لكل كلمة (3) اختبارات محتوى موسعة (4) التناوب قواعد↔كلمات يعمل (5) بنك التمارين يتوسع تلقائيًا |
| L2 | نصوص قارئ بكثافة 72 كلمة | صياغة: الشريك · منطق: المشرف | (1) 2-3 نصوص جديدة ≥30% من كلماتها من المنهج (2) كل كلمة جديدة لها 8-10 لقاءات تراكمية عبر النصوص (قاعدة البحث) (3) تمديد خريطة الشواذ إن لزم (4) قارئ يلوّن ويصحّح الأشكال بلا أخطاء |
| L3 | الصوت أولًا في بطاقة التعليم | تصميم: الشريك · هندسة التخزين: المشرف | (1) قرار موثق لتخزين الصوت أوفلاين (حجم/سياسة SW) (2) زر صوت ≥48px في بطاقة التعليم (3) يعمل أوفلاين بعد أول تحميل (4) لا كسر لأوفلاين-أولًا |
| L4 | تصنيف أدلة القراءة (القراءة كدليل) | قرار معماري: المشرف · عرض: الشريك | (1) مواصفة أحداث قراءة (نوع/وزن/قبول) قبل أي كود (2) لا تغيير في admissibility القائمة دون اختبارات جديدة (3) عرض الحالة في القارئ متوافق مع القناة غير اللونية |

## المرحلة M — رؤية المالك البعيدة (كل بند يبدأ بمواصفة مستقلة)

| # | المهمة | ملاحظة القيد الصريح |
|---|---|---|
| M1 | Word DNA (نموذج معنى/استخدام لكل كلمة) | مواصفة بيانات أولًا؛ قرار المشرف؛ لن يمس أحداث الأدلة القائمة — إثراء فوقها |
| M2 | قارئ يتكيف مع مستوى المتعلم | يعتمد على L2 وL4؛ خوارزمية المشرف · عرض الشريك |
| M3 | الاستماع وفهم الكلام | **قيد يُحسم بقرار المالك:** Web Speech غير موثوق أوفلاين عبر المتصفحات؛ إما سحابة (يكسر أوفلاين-أولًا جزئيًا) أو تأجيل |
| M4 | محادثة/تقييم كتابة وإنتاج حر | يتجاوز حدود PWA الصرفة — قرار استراتيجي من المالك (سحابة أم انتظار) |
| M5 | مسارات مهنية + تقارير تقدم بالأدلة | التقارير تُشتق من سجل الأدلة فقط — لا رقم يُعرض إلا محسوبًا (قيد LOCKED) |
| M6 | مساعدة ذكية تفهم سجل التعلم | لا تحل محل محرك الأدلة (قيد المالك)؛ تعتمد على إعادة نشر دالة AI (قرار المالك) |

## قواعد ثابتة عبر كل المراحل

- كل دمج: اختبارات أخضر (226+) + قياس حي 360px + فحص إنتاجي بعد النشر.
- كل ملف ≤400 سطر (فصل البيانات عن المنطق عند الاقتراب).
- لا تغيير لدلالات ألوان الحالات أو منطق الأدلة/الجدولة بقرار تصميمي منفرد.
- أي قيد جديد أو استثناء: موافقة المالك والمشرف حسب مجال الاختصاص.
- سجل الحالة الأربع (مقترح → مراجَع → مدمج → منشور) يوثق في سجل المشروع
  لكل مهمة — لا يخلط بينها أبدًا.
